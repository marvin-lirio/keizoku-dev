# Keizoku Dev

The official website and ongoing development project for **Keizoku Dev**, an independent development studio focused on software, web development, automation and digital products.

The site is built and maintained as both the public home of Keizoku Dev and a practical environment for developing, testing and refining modern front-end development skills.

---

## About

**Keizoku (継続)** means continuation or persistence.

That idea shapes both the identity of the studio and the way the project is developed:

**Build → Test → Improve → Continue**

Keizoku Dev combines development with a quality-first mindset shaped by experience across software testing, QA, enterprise systems, technical compliance and product delivery.

The goal is not simply to produce working code, but to understand what is being built, validate how it behaves and continuously improve the result.

## Current Site

The website currently includes four primary pages:

### Home

Introduces Keizoku Dev, its areas of focus and selected active projects.

The Home page also includes a continuously moving project reel highlighting current work and concepts.

### Inquiry

Provides the foundation for future project and client inquiries.

The interface is currently implemented as a front-end experience only. Form submission is intentionally disabled until a production submission workflow or backend service is implemented.

### About

Explains the development philosophy behind Keizoku Dev, including:

- Build
- Test
- Improve
- Continue
- Current development tools and technologies
- Quality and automation experience
- AI-assisted development workflow
- Developer background

### Projects

Provides expandable project summaries covering active development work and concepts.

Each project can include:

- Current status
- Project disciplines
- Scope of work
- Development approach
- Current progress
- Repository or project links when available

## Featured Projects

### Horizonte Website Refresh

**Status:** Active / In Development

A refresh and modernization of an existing business website focused on improving structure, presentation, responsive behavior and overall user experience while preserving the purpose and identity of the original site.

Areas of work include:

- Existing-site review
- Information structure
- Front-end development
- Responsive design
- Usability refinement
- Functional QA

---

### Keizoku Dev Website

**Status:** Active / Continuous Development

The design and development of Keizoku Dev's own web presence.

The website is developed incrementally, with each page and interaction implemented, tested and refined as part of the broader site system.

Areas of work include:

- Information architecture
- Visual system development
- Responsive front-end development
- Reusable site structure
- Interactive components
- Functional and visual QA

---

### Fukutsu Fitness App

**Status:** Concept / Pre-Development

An independent fitness product concept exploring a unified experience for training, recovery and progress tracking.

Current concept work includes:

- Workout tracking
- Progress and trend tracking
- Personal records
- Nutrition and macros
- Recovery awareness
- Goal-based training modes
- Product requirements
- Feature prioritization
- UX exploration

Fukutsu is a separate product concept and is not a Keizoku-branded application.
